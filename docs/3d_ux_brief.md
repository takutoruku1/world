# 3D UX改善ブリーフ (for Codex) — プレイヤーの実プレイフィードバック反映

ユーザーが実際に遊んだ上でのフィードバック。UX仕様は下記に厳密に従い、見た目のデザイン判断は任せる。
従来の統合制約(シミュ本体・data/*.json 不変、U.load_texture_file使用、UTF-8読み取り、apply_patchのみ、検証3コマンド)は継続。

## 1. カメラ操作の刷新(最優先・仕様厳守)

現状の不満: 「右ドラッグじゃなく左ドラッグにしてほしい」「ドラッグと画面の移動が合っていない」「QEではなくドラッグで角度・向きを調整したい」

- **左ドラッグ = 回転(オービット)**: 横移動でヨー、縦移動でピッチ。QEキーは残してよいが補助扱い
- **右ドラッグ = パン**: **1:1グラブ必須** — ドラッグ開始時にマウス直下の地面(y=0)ワールド座標を記録し、以後毎フレーム「現在のマウス直下の地面座標」との差分でカメラターゲットを補正し、**つかんだ地点がカーソルに追従し続ける**こと(倍率係数での近似は不可。これが「合っていない」の原因)
- **クリック(移動5px未満で離す) = 住人選択**(従来機能を壊さない)
- ホイール = ズーム(可能ならカーソル方向へ寄るズーム)
- カメラに**スムージング**(位置・回転のlerp補間)を入れて酔いを軽減。ただし操作遅延を感じない程度(強すぎ注意)

## 2. ラベル/状態表示のデザイン刷新

現状の不満: 「文字が重なって見えない」「何をしているか伝わらない」

- 名前Label3Dは `fixed_size = true`(+必要ならno_depth_test)で画面上一定サイズに
- **常時全員に名前を出さない**。表示ルール:
  - 選択中の住人: 名前 + 現在の行動テキスト(例「畑で働いている」)を頭上に表示
  - それ以外: 頭上に小さな**状態バッジ**のみ(billboard)。💤睡眠 / 🍚食事 / ⚒仕事 / 🙏祈り / ✨修行 / 🔨建設指揮 / 🚶移動(なし可) / 会話は既存の吹き出し
  - ズームが十分近い時(カメラ距離しきい値)は全員の名前を表示してよい
- 同じ場所に複数人いるとき、バッジ/ラベルの高さを人ごとに少しずらして重なりを軽減
- 主人公は常に名前表示(金色)で特別扱いを維持

## 3. マップ外周(画面酔い対策)

現状の不満: 「マップの外が空背景で、宙に浮いている感じがして画面酔いする」

- マップの外側に**広大な周辺地面**(マップの10倍以上、同系の落ち着いた緑、フォグに溶ける)を敷き、島が宙に浮いて見えないようにする
- 周辺の遠景に**山並みのリング**(低ポリの山を数個〜十数個、フォグで霞む)を配置して地平線を作る
- カメラのピッチ・ズーム上限を調整し、地面の切れ目や地平線の裏側が見えないようにする
- 空パノラマは引き続き見えること(周辺地形とのバランスは任せる)

## 4. 品質向上(このラウンドで入れる)

- **影**: DirectionalLight3D の shadow_enabled = true。シャドウ距離/バイアスを調整し、建物・住人・木が地面に影を落とすこと(パフォーマンス: このシーン規模なら問題ないはず)
- **Environment**: tonemap を FILMIC か ACES に。glow を有効化(夜の祠・魔法建物の発光がにじむと美しい)。SSAOは負荷を見て任意
- **住人の移動アニメ**: 進行方向へ体を向ける(スムーズに回頭)、移動中は軽い上下ボブ(歩行感)。動物も同様に任意で
- **パーティクル(少量)**: 祠から立ちのぼる光の粒。夜だけ現れる蛍(数匹)。鍛冶場が建ったら煙突の煙。GPUParticles3Dで軽く
- タイトル画面・対話UIとの調和は維持

- コミットはしない
