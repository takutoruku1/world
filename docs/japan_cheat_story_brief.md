# ストーリートーン改修ブリーフ: 「日本の知識チート」を持つ転移者アシタ

## 問題(ユーザーフィードバック原文)
- 「もっと主人公が日本のチートを使うようにしてほしい」
- 「ストーリーがただ神を進行している現地民になっている」

つまり今のアシタは「神さまの言うことを聞くだけの村人」に見える。
本来の設定は **現代日本から転移してきた若者** で、前世(日本)の知識を
チートとして使い、神(プレイヤー)の導きと組み合わせて文明を一気に進める
「なろう系主人公」の爽快感が欲しい。

## 対象ファイル(テキスト値のみ変更可。JSONのキー・構造・IDは変更禁止)
1. **data/story.json** — プロローグ全面書き直し。
   - 日本で暮らしていた記憶(通勤電車、コンビニ、田んぼの風景など具体的に)
   - 気づいたら異世界の森にいた戸惑い → 空から神の声
   - アシタは神に対して**対等な相棒**の口調(敬意はあるが従属ではない)。
     「神さまの力とぼくの日本の知識、合わせたら最強だと思いませんか？」のような
     前向きな共犯関係を打ち出す
2. **data/dialogue.json** — 全プール増強(既存行の書き換え+行の追加OK):
   - prayer_first / prayer_normal / prayer_solo / prayer_hungry / prayer_danger:
     「今日は日本の◯◯を試したい」のような提案型の台詞を混ぜる。
     例:「神さま、堆肥って知ってます？　落ち葉と糞を混ぜると畑が生き返るんです」
   - chatter_common / chatter_era0..4: アシタや村人が日本由来の知恵を話題にする。
     時代が進むほど「日本の記憶が現実になっていく」感慨を入れる
   - talk_hero / talk_reply: アシタが村人に日本の知識を教える構図を増やす
     (稲作、輪作、味噌汁、風呂、そろばん、たたら製鉄、水車、衛生観念など)
3. **data/events.json** — 各イベントの choices[].response のみ調整可。
   アシタが日本の知識で対処法を思いつく言い回しに(構造・effects・条件は触るな)
4. **data/chapters.json** — 各章の catch(キャッチコピー)のみ調整可。
   「日本の記憶が、この世界の未来になる」系の縦軸を通す

## トーン指針
- 文体は現行踏襲: やわらかい日本語、体言止め少なめ、絵文字なし
- アシタ一人称は「ぼく」。神への呼びかけは「神さま」
- 「前の世界では」「日本では」「向こうの世界の」を口癖レベルで使う
- チート感=知識の具体性。ふわっと「いい方法」ではなく固有名詞
  (高床式倉庫、ネズミ返し、輪作、寺子屋、たたら、曲がり家 等)
- ただし説教臭くならない。1台詞1ネタまで
