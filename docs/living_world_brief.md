# 生きた世界・演出強化ブリーフ (for Codex)

プレイヤーの要望をまとめた大型ビジュアルラウンド。統合制約(シミュ本体不変・U.load_texture_file・Label3D fixed_size禁止・カラー絵文字禁止・カメラ操作変更禁止・UTF-8読み・apply_patchのみ)は継続。

## 1. アシタの3Dモデルを立ち絵に寄せる(最優先)

立ち絵 `assets/portraits/ashita_normal.png` を見て、3Dキャラを寄せる:
茶色のくせ毛(髪メッシュを複数の球/カプセルで)、こはく色は無理でも顔は肌色球のまま可、
**クリーム色のチュニック + 紫の腰帯 + 木のお守りネックレス**を胴体の色分けで表現。
村人も髪の色・髪型(球の組合せ)・服色にバリエーションを付けて個体差を出す(idのhashで決定的に)。

## 2. 生活演出

- **釣り**: 川辺(riverbank)で働く住人は釣りポーズ — 細い釣り竿(cylinder)+釣り糸+水面の浮き。ときどき竿がぴくっと動く
- **睡眠**: SLEEPING状態の住人は横たわる(体を倒す/縮める)+頭上にゆっくり浮かぶ「z」の光の粒(GPUParticlesかLabel3Dの"z"複数)
- **山仕事**: 山で働く住人は斧を振るモーション(小さな傾き反復)があると良い(任意)

## 3. 山の立体化

「山」サイト(forest, 左上)が平面で不自然。**ちゃんと隆起した山**にする:
- 山体(重なった円錐群)が奥にそびえ、**手前の麓に平らな採集広場**(住人が働く場所=既存のstand位置)がある構成
- 労働者が山体にめり込まないこと(作業エリアは平地に保つ)
- 遠景の山並みリングと調和させる

## 4. 新しい動物モデルの仕上げ

新種を仮モデルで追加済み(animal.gd): **うし(cow)/ひつじ(sheep)/うま(horse)/ねこ(cat)**。
仮の造形を、既存の鹿・犬・鶏・やぎと同じ品質水準に磨き上げる(牛の斑、羊のもこもこ、馬のたてがみと尻尾、猫の耳と長い尾)。

## 5. 森スタートの木々

マップを覆う伐採可能な木(terrain.gd の clearable_trees / _clearable_tree_visual)を美しく:
種類のバリエーション(広葉樹/針葉樹/背の高低)、色の揺らぎ。**ただし clear_trees_rect の仕組み(木の親Node3Dをqueue_free)は壊さないこと**。

## 6. 魔物の気配(任意・軽く)

夜(22:00〜04:00)にマップ外周の森に、赤く光る目のペア(小さな発光球2つ)が数カ所ゆらめくと、魔物イベントの存在感が出る。軽量に。
