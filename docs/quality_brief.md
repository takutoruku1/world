# 画面クオリティ向上ブリーフ (for Codex)

プレイヤーの要望「画面のクオリティをあげて」。実装済み: 影 / FILMIC トーンマップ / glow / テクスチャ / 空パノラマ / 昼夜ライティング。この上で総合的な絵作りの品質を上げる。統合制約(シミュ本体・data/*.json不変、U.load_texture_file、UTF-8読み、apply_patchのみ、検証3コマンド)は継続。

## やること(効果と負荷のバランスは君の判断で)

1. **アンチエイリアス**: viewport の MSAA 3D (2x〜4x) or TAA。ジャギーを消す(project.godot 設定でもコード設定でも可)
2. **SSAO / SSIL**: 建物と地面の接地感向上。負荷を見て有効化・調整
3. **水の生命感**: 川のUVスクロール(ゆっくり流れる)、わずかな透明感・光沢
4. **マテリアルの質感**: 建物・地形の roughness/specular を見直し、プラスチック感をなくす。屋根・石・木で質感差を出す
5. **ライティングの絵作り**: 朝・昼・夕・夜それぞれのカラーグレーディング(Environment adjustment / 色調整)を微調整し、夕方の金色と夜の青の「決まってる感」を強める
6. **パーティクル増強**: 祈りの岩/祠の光の粒、夜の蛍、焚き火の火の粉(野営地camp)、鍛冶場の煙。すべて軽量に
7. **住人の生き生き感**: 歩行ボブの質、選択リングの発光、話し中の小さなアニメ等、気づいた範囲で
8. **描画距離・フォグの調整**: 遠景の山並みが美しく霞むように

## 検証

- tools\godot\Godot_v4.6.3-stable_mono_win64_console.exe で (1)--quit SCRIPT ERRORなし (2)--selftest OK (3)--shot / --shot-day / --shot-night を撮って昼・夕・夜の絵を自分の目で確認し、白飛び・真っ暗・ジャギーがないこと
- フレームレートを大きく落とさないこと(GPUはRTX 3060 Laptop)
- コミットはしない

## 注意

- Label3D は fixed_size = false を維持(fixed_size は巨大化バグがあるため使用禁止)。カラー絵文字もLabel3Dで使用禁止
- カメラ操作(_rotate_camera / パンの1:1グラブ)は変更しない
