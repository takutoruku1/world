# 神対話のビジュアルノベル化 + 建物クオリティ改善ブリーフ (for Codex)

プレイヤーの声: 「淡々とゲームしている感じ」「主人公と会話する部分が作業になっている」「小屋のクオリティが低すぎる」。
神対話を"儀式の時間"として演出し、作業感をなくす。従来の統合制約(シミュ本体不変・U.load_texture_file使用・UTF-8読み・apply_patchのみ・検証3コマンド)は継続。

## 1. アシタの立ち絵(生成済みアセット)

`assets/portraits/ashita_<mood>.png` — 腰上、1024x1536。mood: normal / smile / worried / surprised / determined。
**注意: 背景は透過ではなく、金色の光のグラデーションが描き込まれている。** そのため切り抜き前提ではなく、**角丸の額縁(フレーム)に入れてクリップ表示**する前提でデザインすること(金色の光背は神との対話の演出として好相性)。

- events.gd の convo に **"mood" キー実装済み**(通常祈り=normal、食料難や危機の朝=worried、時代UP=determined、イベントはevents.jsonのmood)。dialogue_ui.open の引数に mood を追加してよい(main.gd の呼び出し側も併せて修正可)
- 立ち絵を**対話ウィンドウの左**に表示。ウィンドウの上にはみ出す配置(VN風)。moodで差し替え
- 応答ページ(選択後のアシタの返事)の表情は、選んだ内容に応じて君のデザイン判断で(例: 魔法を授けた→smile、危機の重い選択→worried)
- 演出: 開くときに立ち絵がふわっとフェード+スライドイン、mood切替時にクロスフェード等。タイプライター表示は維持。**クリック回数は増やさないこと**(応答ページはクリックで閉じる実装済み)
- 立ち絵ファイルが無い場合は従来レイアウトに自動フォールバック

## 2. 対話ウィンドウ全体の演出強化(作業感の払拭)

- 話者名プレート、ウィンドウの開閉アニメ(すっと出てすっと消える)、背景をわずかに暗くするなど「神と対話する特別な時間」の空気を作る(具体は任せる)
- 選択肢ボタンのホバー演出を少しリッチに(既存テーマと調和)
- 祈りのときに祠の3D側でも何か起きると良い(例: 光の柱、パーティクル増量) — 任意

## 3. 小屋(と建物全般)の造形改善

プレイヤー評: 小屋のクオリティが低すぎる(上からだと平らな板に見える)。
- 小屋: きちんとした**切妻屋根(わらテクスチャtex_thatch)**、木の壁(tex_wood)、ドア・窓、屋根の張り出し。デフォルトカメラ角度(斜め見下ろし)で「家」と分かる高さ・形に
- 他の主要建物(祠・学び舎・鍛冶場など)も同じ観点で高さと屋根の存在感を確認、必要なら調整
- 個体ごとに色味をわずかにランダム化して単調さを回避
